# Starryear-Ink 星年水墨

将一张真实摄影转译为一张连续的竖向纸本作品：

`摄影证据 → 干性印刷记忆 → 彩墨余像`

Starryear-Ink 保留原照片的直接证据带，让场景在向下移动时逐步碎裂、抽象并释放为来源绑定的彩墨关系。它不是整图水墨滤镜，也不是传统山水画风格转换。
